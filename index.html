Калькулятор заявок — Фасады

1. Введите количество по фасадам

Пустые поля считаются как 0 и не участвуют в расчёте.
№ Наименование Цвет Кол-во

2. Стекло — по цветам

Цвет стекла определяется цветом фасада, в который оно входит. Для каждого цвета — общий итог.
Цвет / Размер, мм Кол-во, шт

3. Планки — по цветам

Все планки сгруппированы по цвету фасадов. Для каждого цвета — общая длина.
Цвет / Длина, мм Кол-во, шт Общая длина, мм Общая длина, м

6. Раскрой планок — карта для оператора

Программа распределяет детали по отдельным профилям. Каждый профиль раскраивается полностью, затем берётся следующий. Профили разных цветов не смешиваются.

4. Фурнитура — пакетики с петлями

Цвет не важен. Считаем, сколько пакетиков с 2, 3 и 5 петлями нужно собрать.
